# Free Fire Training Companion

A small Android/Kotlin starter app for legitimate Free Fire practice.

## Features
- Training drills
- Sensitivity presets
- Session counter
- Local preference storage
- Dark gaming UI

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Connect an Android phone or start an emulator.
4. Press Run.

The project intentionally does not automate, inject into, modify, or control Free Fire.
